# Number Analyzer CLI 

A simple command-line Python application that analyzes a number and provides useful insights.

 Features
- Count total digits
- Calculate sum of digits
- Count even and odd digits
- Find largest digit

 Technologies Used
- Python
- CLI (Command Line Interface)

How to Run

bash
python main.py
>Example

Enter number: 1234

Even digits: 2
Odd digits: 2
Largest digit: 4
